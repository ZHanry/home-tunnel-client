# 升级与恢复

GUI 的“下载更新”只下载并校验完整包，不会自动退出、覆盖正在运行的程序或启动安装器。它只读取客户端仓库的稳定 Release：7.0 用户不会自动安装 8.0 RC，已安装 RC 的用户也不会被降级到较旧的 7.0 稳定版。正式 8.0 发布后，版本比较允许 RC 更新到 8.0。

RC 必须从明确选择的 prerelease 手动下载完整包，按该 Release 的校验清单验证。稳定入口和默认通道继续保持稳定版；本项目尚未实现自动候选通道或事务式桌面自更新。

## Windows 安装版

安装目录内有 Inno Setup 的 `unins000.exe` 时，GUI 选择完整 Setup EXE。升级前备份用户数据并保留上一版完整安装包，在界面或托盘选择“退出程序”，等待远程会话、输入和后台进程停止。关闭窗口只会隐藏到托盘。

安装包包含相互匹配的 GUI、Agent、原生 worker、构建来源与许可证。新 GUI 固定了同包 worker 的 SHA-256；混用不同版本的 worker 会使远程能力不可用。安装器不通过 Restart Manager 强制终止 worker 和同名的输入释放守护进程；目标 EXE 仍在运行或不可写时，会拒绝继续并要求先退出。

安装失败时按安装器错误信息处理。只有在原有进程已完全停止后，才用上一版完整包恢复；不要把单个旧 EXE 混回新目录。跨版本安装器回滚、断电及磁盘故障仍须在隔离 Windows 环境实际验证，不能把下载校验通过当作升级成功。

## Windows 便携版

没有安装器标记的目录选择完整 Windows ZIP。退出程序后将 ZIP 解压到一个新目录，保持完整结构，再从新目录启动。保留旧目录，确认新版本隧道与远程能力正常后再自行清理。恢复时退出新版本，从旧的完整目录重新启动；用户数据共用，应在首次运行新版本前单独备份。

下载失败、校验不一致、长度异常或中途取消不会替换已有下载，也不会修改安装目录。重复下载通过校验后才替换旧下载文件；这不是应用升级回滚。

## Linux 与 macOS

GUI 下载当前平台与架构的完整 tar.gz。系统安装版解压后按包内说明运行 `sudo ./install.sh --upgrade`；便携运行保持完整包目录结构并从新目录启动。当前这些平台不分发可用的原生远程 worker，升级不得把 Windows 的原生验收结果当作 Linux/macOS 能力证明。

安装脚本要求所有 Home Tunnel GUI 正常退出后再改动程序文件，不会替用户强杀桌面进程。`pgrep` 用于检查 GUI 是否仍运行，检查工具不可用或失败会中止安装。此前运行的 systemd/launchd 隧道服务在文件替换前停止，完整更新后按原状态恢复。

备份全部完成之前不修改旧程序。安装失败或收到中断时恢复已备份的文件；如果恢复本身失败，保留临时备份目录并保持服务停止，错误信息会给出目录，待人工恢复完整包后再启动服务。安装脚本不改写已保存的设备凭据，但这不替代升级前的用户数据备份，也不保证掉电、文件系统损坏或磁盘完全耗尽后的自动恢复。

CLI/NAS 保持独立入口和独立设备状态；它们不需要启动 GUI、启用远程桌面或取得桌面批准。使用各自的完整包、服务安装流程或容器镜像升级，保留其专用数据目录；不要把桌面用户的状态文件复制给后台服务。

## 版本连续性验收

以下是需要用实际发布产物执行的检查矩阵，不是已经完成的认证记录：

| 路径 | 更新方式 | 仍需实际验证 |
| --- | --- | --- |
| 7.0 → 首个 8.0 RC | 明确选择 RC 的完整包，手动安装 | 保留登录/设备/隧道配置，首次远程登记与批准，新旧安装器兼容 |
| 8.0 RC → 后续 RC | 明确选择后续 RC 的完整包 | GUI/Agent/worker 全部对应同包，旧授权与连接 epoch 不会恢复控制 |
| 8.0 RC → 正式 8.0 | 正式发布后由稳定入口提供完整包 | 正确版本比较、真实包内容、升级后重新连接和本地批准 |
| 7.0 → 正式 8.0 | 正式发布后由稳定入口提供完整包 | 与经过 RC 的设备得到同样的有效配置和权限状态 |
| 任一步失败或回退 | 保留的上一版完整包与用户数据备份 | 活跃输入已释放、无混代后台进程，恢复后的隧道/设备凭据与服务状态 |

每个 Windows 安装/便携场景以及 Linux/macOS 实际服务场景都要分别记录结果。尤其要验证持有按键或鼠标按钮时退出升级、断网、旧进程仍运行、写入失败及恢复失败，观察真实输入释放和最终包哈希。当前自动回归覆盖稳定通道与版本比较、包型选择、下载完整性，以及在临时文件系统中执行的安装脚本故障恢复；它们不替代真实系统的连续升级验收。
