# HomeDesk 名称核查

2026-10-03 用户最终确认产品名称为 **HomeDesk**，Windows 程序和包的基础名称为 `homedesk`。以此拼写为准，取消测试后缀，替代此前临时拼写。

| 核查入口 | 处理 |
| --- | --- |
| 构建示例及当前 Windows 构建配置 | 显示名使用 HomeDesk，程序名称使用 homedesk。 |
| 窗口标题、托盘、安装动作及关于页标题 | 从同一构建品牌读取。 |
| 网络页及网络模式弹窗 | 去除写死的 HomeDesk，读取实际品牌。 |
| Windows 文件产品名、发布者、描述、原始文件名 | 使用生成的品牌资源；描述不附带 Remote Desktop。 |
| 关于页蓝色宣传框、口号及上游品牌外链 | 移除；保留普通文字的来源、版权、版本和许可证说明。 |
| 根 README 和当前设计契约 | 当前产品名称更新为 HomeDesk。 |
| Windows 隧道助手 | 重新构建并绑定 homedesk.exe，避免改名后拒绝父进程。 |
| 配置及登录状态 | 升级构建显式保留原配置 namespace 与 Windows 登录密文目录，不复制设备密钥或令牌。 |

以下名称具有兼容或来源含义，不作为另一个产品名：

- `HOMEDESK` 修改标记、构建环境变量、Rust/Dart 模块、选项键、API 路径、服务内部标识和 DPAPI 固定熵继续保留。改变它们会影响上游补丁合并、服务器接口或已保存登录的解密。
- `HomeDeskAcceptance` 仅用于现用升级构建的旧配置 namespace，以及已存在的历史设备名称和历史验收记录。界面去除旧设备名称自动附加的品牌后缀；服务端原始设备名称保留，不通过品牌更名批量覆盖用户设备。
- RustDesk、home-tunnel、FRP、Purslane 继续用于开源来源、版权和依赖身份，原 LICENSE 与第三方声明保留。
- 旧交付 ZIP、历史日志、已停用服务和用户已配置域名保留原名称。它们不进入本次新客户端包。
- 未构建的上游移动端及平台发行模板保留原始来源；本次已交付和验证范围为 Windows x64。

当前配置通过 `brand.app_name`、`brand.executable_name`、`brand.package_name` 统一品牌。可选 `brand.config_namespace` 只用于明确的旧身份目录兼容，省略时使用新品牌；该字段同样拒绝目录路径、控制字符与不合法名称。
