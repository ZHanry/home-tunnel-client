# HomeDesk 家庭设备中心 UI 改版

更新时间：2026-09-08。

## 目标与范围

本轮将桌面首页调整为“家庭设备中心”，服务于家庭内网设备的查看、连接与唤醒。页面遵循 `docs/DESIGN.md` 第 6.4 节：设备入口、最近连接、ID / 内网 IP 手动连接，以及清晰的网络状态入口。未改动传输协议、编解码或加密逻辑。

## 已交付界面

- 左侧导航提供“家庭设备”“最近连接”“本机信息”“设置”。
- 主区域使用设备卡片网格，按房间筛选；卡片显示在线状态、连接、WOL 和离线时的次级“尝试连接”入口。
- 顶栏“手动连接”使用描边按钮，弹窗只接受设备 ID 或内网 IP；默认不显示本机凭据。
- 状态区域提供文字说明和网络设置入口；本机信息在独立弹层中查看。
- 支持浅色、深色、窄窗口和放大字体；设备服务未接入或没有设备时显示真实空态并保留手动连接入口。
- 设置页明确 HomeDesk 定制，同时保留 RustDesk 来源、AGPL-3.0 和版权信息；连接页补充更清晰的状态文案与缩放体验。

## 审计与验证证据

- Gemini 仅审查合成预览，结果为无 Blocker。其“手动连接过重”和“状态入口不清”的意见已分别通过描边按钮、状态文案和网络设置入口处理。
- 离线设备优先提供 WOL，保留次级“尝试连接”入口；该行为符合先开机再连接的家庭场景设计。
- 常规 Flutter 组件测试共 6 项通过，覆盖设备墙、手动连接、默认隐藏本机信息、房间筛选、窄窗口/双倍字体和空态；只在本机启用预览环境变量时，额外导出 1 项深浅色合成预览（共 7 项）。CI 不启用该环境变量。
- Windows Release 构建成功；本机已安装版本曾重新启动并可响应，且安装文件与构建文件摘要一致。

## 当前边界

- 这是合成图目视、组件测试和本机进程验证，不代表真实双机远控、ARM/麒麟适配、WOL 实机或完整 Windows 视觉验收。
- 当前安装仍为测试服务器配置，设备服务未接入时会显示真实空态。
- 旧 portable 验证包没有随本轮 UI 改版重新打包，仓库尚未为本轮新增 Git 提交。
- CI 覆盖首页与设备模块的静态分析和组件测试，但不设置仅供本机合成预览使用的环境变量。
