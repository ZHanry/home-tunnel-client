# NestLink 14.0.0

Windows 与 Linux 客户端采用统一紫色品牌、设备分组、工作台、账号与设置界面。远程控制、穿透服务、设备管理和连接凭据保持独立清楚的入口；设备能力决定可用操作。

保留自建 HTTPS 账号登录、记住登录、自动续期、可撤销设备会话和短期远控许可。远控使用认证加密的 P2P 直连。Windows 安装器和 Linux x64/ARM64 DEB 内含受管穿透执行器，运行版本与产品版本均为 14.0.0。

发行目标为 Windows x64 安装器、Linux x64/ARM64 DEB、对应源码与构建材料 ZIP、SHA256SUMS。保留安装器身份与配置命名空间，支持原安装升级。Windows 当前未配置 Authenticode 证书，不能将构建签名证据描述为平台代码签名。

14.0.0 的最终构建、安装与联调正在验收；仅版本对应的真实验收记录和最终产物哈希能够允许发布。13.0.0 的记录保留在 release/acceptance-13.0.0.json，不能作为本版验收。Android 真机、运营商 NAT、长期媒体和其他未实际运行场景仍需明确列为未验证。
