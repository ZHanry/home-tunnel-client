# NestLink 14.0.0 桌面与三端统一

本轮以当前桌面客户端为设计基准，重构服务端和 Android，共同发布 14.0.0。三端统一品牌、图标、名称与设备能力语义；生产升级与 GitHub 发行分别验证。本地构建材料不能冒充正式验收或已发布产物。

- 产品显示名称统一为 **NestLink**。
- `brand/icon.svg` 导出紫底白色连接 N 图标；桌面快捷方式、程序窗口、托盘、安装器和界面使用相同资源。
- 首页为“设备管理”；侧栏保留“设备管理、远程协助、内网穿透”三个平级标签，下方固定显示账号入口，进入合并后的“账号与设置”页。普通侧栏文字为 15 像素，紧凑布局为 12 像素。删除旧导航分组、“我的设备”模块及收藏入口、星标和收藏排序。
- 电脑与手机/平板分组显示；支持名称/设备 ID 搜索、在线/离线筛选、折叠和设备信息。搜索、手动连接、筛选与刷新统一放在设备管理标题行右侧，窄窗口在同一页头内换行，不显示设备总数。
- 设备管理覆盖所有账号设备，包括仅提供穿透服务的设备；可查看远控绑定、编辑标签、管理该设备的穿透服务及删除设备。删除使用现有账号设备撤销接口，确认后停止设备访问并刷新服务端目录，不调用管理员物理删除接口。
- 连接仍使用当前账号的关联远控 ID，检查在线状态、服务器配置和账号所有者。现有认证与被控批准流程保留。
- 浅色为淡紫导航和白色列表，深色为对应紫色主题。
- 登录页采用左侧淡紫连接示意、右侧表单，内容区不重复显示大 Logo；主按钮为“登录”，无管理台按钮或记住登录勾选项。支持安全存储时默认保存可恢复会话，密码不保存。
- 退出登录统一在账号管理页操作，清理本机会话与安全登录缓存，之后不再自动登录，直到用户主动再次登录。穿透页不再提供退出或取消记住登录操作。
- 输入框鼠标悬停时保持原色；登录支持 Tab、Shift+Tab、回车及数字键盘回车，提交中阻止重复请求。
- 主题、语言和版本入口统一位于标题栏右侧，登录前后都能使用；侧栏不再重复显示这些入口。版本入口仅显示图标，具体版本号在弹窗中查看。标题栏使用 20 像素 Logo 与 14 像素中等字重名称，紧凑排列并垂直居中对齐。
- 账号入口位于登录后的侧栏底部，页面保留账号管理与网络配置；远控密码与授权统一位于远程协助“本设备”的齿轮入口，包括固定/一次性密码、一次性密码长度和数字密码选项。切换账号后清除密码草稿并忽略旧保存回调。未登录及退出后只显示登录页，隐藏整个侧栏，主题、语言和版本仍可从标题栏设置。删除桌面便携运行与安装引导。
- 删除桌面“本机共享”入口与弹窗，真实本机设备 ID 和一次性密码直接显示在远程协助页，可复制 ID 和刷新密码。退出、原生账号未就绪、服务停止或不使用临时密码的验证方式下不显示旧密码。移动端原有共享组件保留。
- 远程协助按参考图采用上下布局：上方“本设备”横向显示 ID 与一次性密码或真实验证状态，下方“远控伙伴设备”包含并排的输入框和连接按钮，以及最近连接。窄窗口与大字体下字段改为纵向排列；最近记录使用紧凑卡片，保留原有连接和操作菜单，不恢复收藏功能。
- 远程协助的远控设置采用“连接与密码、远控权限、安全保护”三个分区。固定密码在专用弹窗中设置/修改并再次确认；未设置固定密码时，先完成密码保存，再启用仅固定密码或对应的密码连接方式，取消与失败均保留原验证方式。保存中禁止重复提交，账号切换销毁旧弹窗和草稿。默认授权方式与原生“密码或本机确认”保持一致，此方式为任一满足即可连接。
- 远控权限恢复自定义、完整控制、仅查看屏幕，以及键鼠、剪贴板、文件传输、音频、摄像头、终端、TCP 隧道、远程重启、录制、打印、本机输入锁定、支持时的隐私模式和远程配置。预设模式显示实际生效权限并禁用单项编辑，切换回自定义保留原单项值。安全保护保留空闲断开/超时、被控期间唤醒、主窗口限制、设置锁定 PIN、LAN 发现、IP 直连/端口、来源 IP 白名单和已安装 Windows 服务支持的 RDP 共享。保持原生固定策略、PIN/管理员解锁和账号就绪检查，读取或保存失败不显示虚假的成功状态。
- 自建服务连接仅打开当前服务地址与远控服务器的专用窗口，不再打开旧常规、安全、ID 或关于设置。删除旧设置页底部网络/账号状态条。桌面设置与托盘均不提供单独停止后台服务的入口；内部组件由应用登录、退出和撤权流程管理。
- 输入框、筛选框和同一行按钮按可见边框对齐，在 100%、125% 与 200% 字体下验证高度和上下边缘；侧栏内网穿透不显示数字。设备和穿透目录刷新保留已有内容，进度显示在原刷新按钮内，不插入进度条改变列表位置。
- 内网穿透标题行不显示设备/服务计数、新建能力提示或账号状态栏；刷新放在标题工具栏。正常时不显示状态角标，异常时在标题后显示感叹号，悬停查看具体问题，点击进入原有详情和重试流程。
- 桌面弹窗采用统一标题、可滚动正文和固定底部操作区，适配窄窗口与放大字体；标题区域可在应用内拖动弹窗，保持普通鼠标指针和固定尺寸。弹窗不显示右上角叉号，关闭与取消位于底部，不可取消操作保持原授权约束。内网穿透只显示一个页面标题，筛选与新增按钮按可用宽度排列。
- 主窗口显示和收起时均保留托盘图标，退出程序时移除；Explorer 重启后重建图标。点击任务栏图标按 Windows 常规方式最小化和恢复，保留任务栏入口；只有显式“最小化到系统托盘”操作隐藏窗口。

本轮客户端、服务端、Android 与受管 Agent/穿透/浏览器辅助运行时的目标版本统一为 14.0.0。基础 API v2 保留原冻结字节，设备能力扩展独立版本为 nestlink-device-capabilities-v1。Android 固定当前客户端共享 Flutter/Rust 提交，保留应用 ID 与原发行证书，versionCode 为 14000000。
原生启动校验按编译时嵌入的 `compatibility.json` 中 `target_combination.agent` 核对运行时版本，并继续校验助手/Agent 的 SHA-256 和父进程名称。客户端版本与运行时版本分别维护；版本不兼容与文件摘要失败使用不同错误提示。本地打包也检查该版本组合。

## 一台设备的两项能力

14.0.0 以物理设备为目录单位，同一台电脑的远程协助和内网穿透在同一行分别显示状态，在线数量只计一次。GUI 与 background 仍保留各自的凭据主体和授权规则：远控需要有效账号及原生授权，穿透服务使用该设备的隧道主体。服务归属、创建、元数据和删除按当前有效能力路由操作，不能把显示用的统一 ID 直接发送给所有接口。

旧服务端下，只配对当前账号、已批准 origin、本应用受控原生 Agent 校验得到的本机 GUI 与隧道 UUID；名称相同不会合并设备，真实纯远控或纯穿透设备继续保留。刷新沿用已确认关联；目录请求合并，并在注册、关联、写操作和结果未知时使旧快照失效，迟到结果不能恢复重复设备或过期服务。

配套服务端迁移 026 新增明确的设备能力关联和原子整机撤销。部署后，支持该协议的其他客户端可以读取权威关联。服务端源代码和协议已在相邻 home-tunnel-server 仓库完成测试，并纳入本轮 Web/Android 统一；各端仍需自己的最终安装与联调验收，本地桌面安装不代表生产部署已更新。旧服务器的整机撤销依次撤销两项主体；部分完成或结果未知时要求刷新核对，不自动重放。

底部账号选中背景上下各增加 4 像素，整体增加 8 像素；业务导航、字体和配色保持一致。

## 编译与本地打包

使用现有锁定的 Flutter、Rust 1.96、MSVC 2022 和 vcpkg。中文路径下可将源文件同步到用户缓存目录再构建；资源和源码应与本机工作目录一致。运行原生库编译、Flutter Windows Release 编译和桌面组件回归后，用 `scripts/package-desktop-local.py` 打包。脚本记录本地来源、实际运行时版本、安装器及载荷 SHA-256，不伪装成已发布构建。

## 每次安装必须先清理

```powershell
./packaging/windows/install-local-clean.ps1 -Installer '<本地安装器绝对路径>' -BuildReceipt '<local-build.json绝对路径>' -Launch
```

可先加 `-PlanOnly` 检查目标。实际执行会关闭属于原安装目录的进程，备份旧安装、原生配置和独立的加密登录缓存到 `%USERPROFILE%/.cache/NestLink-LocalBackups/<时间>`，运行旧卸载器，删除原安装、配置和对应快捷方式，再全新安装。脚本只允许清理固定的本产品目录，拒绝文件系统重定向目录，并在安装后逐文件核对构建回执。

安装到 `%USERPROFILE%/Applications/NestLink`，避免 Codex 的 MSIX AppData 写入重定向导致桌面快捷方式和图标指向不存在的路径。脚本同时清理本机旧 `Home Tunnel` 安装和 Codex 中该产品的重定向副本；如需通过当前重定向环境访问原始 AppData，会仅访问本机卷共享中的指定产品目录。安装后核对真实磁盘路径、桌面快捷方式目标和共享 ICO。

全新安装后需重新确认服务地址并登录。旧配置备份位于仓库之外，不会进入源代码或安装载荷。

真实设备的远控网络联调与本轮界面/安装验证分别记录。合成设备预览不会冒充真实登录或远控验收。
