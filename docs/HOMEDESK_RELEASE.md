# nestlink 13.0.0

正式版统一名称 nestlink、图标和蓝白工作台。桌面按远控、内网穿透、设备、设置组织；共享本机、设备 ID、最近连接与会话状态集中呈现。主工作台固定 1120×760，按可用屏幕和 DPI 缩小，禁止自由缩放和最大化；远控窗口保留全屏。浅色、深色、空状态、分页和更新弹窗统一，隐藏可见滚动条并保留滚动操作。

发行 Windows x64 GUI 安装器，以及 Linux x64/ARM64 GUI DEB。桌面提供远控、被控和内网穿透中枢；不再分发独立 CLI/NAS，不发布 macOS。Web 提供浏览器内远控，Android 使用同源组件，保留原应用 ID 和发行证书。

启动后必须登录自建 HTTPS 服务，自动获取连接配置。账号密码、自动续期和可撤销设备凭据取代旧入口，Windows 使用 DPAPI，Linux 使用 Secret Service。移除 MFA、恢复码和设备接入码。跨账号按设备 ID 协助仍须被控端批准或验证密码；原生核心在发起与接受连接时检查短期许可，保持认证加密的 P2P 直连，直连失败明确结束。认证契约固定为 api-v2.0.0。

远控与后台穿透分别管理。关闭远控或撤销前台会话不会停止独立的 HTTP/HTTPS、TCP/UDP 穿透；撤销后台设备停止其对应服务。保留穿透协议、端口池、访问控制和流量治理。桌面和托盘提供后台管理入口。

发布复用 [构建 37960914602](https://github.com/ZHanry/home-tunnel-client/actions/runs/37960914602) 的三份实际安装器字节。Windows runner 通过安装、115 个文件摘要、版本、协议注册、启动、卸载和隔离升级预检；Linux 两架构通过实际 DEB 安装启动、Secret Service 跨进程存取、注销与损坏恢复检查。

实际安装的 Linux x64 GUI 通过跨账号批准、真实画面、键盘输入、两端直连、登录冷恢复、自动续期及撤销后断开。浏览器通过真实画面、输入、DTLS 与非中继 UDP 候选检查；拒绝、密码错误、离线时零帧，撤销后关闭连接。四类穿透在关闭远控、撤销前台会话后仍工作。网站桌面截图来自该安装版的原始像素。

详情见 [13.0.0 验收记录](release/acceptance-13.0.0.json)。发行包含 Windows 安装器、两种 DEB、材料 ZIP 和 SHA256SUMS；材料含对应源码、许可证、构建与 Sigstore 证据。最终标签只增加验收和发行文档，运行源码与被验收构建一致。本次不升级生产部署，历史标签和发行材料保留。

Android 真机、运营商网络、长期媒体、Windows/ARM64 实际远控媒体、Wayland、多显示器/DPI 实机矩阵及正确固定密码连接尚未验收。浏览器当前覆盖画面与键鼠，JPEG 上限 1920×1080、约 6.7 fps；音频、文件与剪贴板未纳入本次验收。Windows 安装器没有 Authenticode 发布者签名。
