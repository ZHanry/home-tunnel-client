## 一、[AGENTS.md](http://AGENTS.md)（放仓库根目录，Codex 自动读取）

```markdown
# AGENTS.md — HomeDesk 开发规则

## 项目是什么
基于 RustDesk fork 的家庭自建远控（默认纯内网，可选显式启用自建公网 P2P；服务端 + 客户端 + 自研管理台 console）。
完整设计方案见 docs/DESIGN.md，它是唯一需求来源；实现与方案冲突时，以 DESIGN.md 为准。

## 技术底座
- client/ = fork 自 rustdesk/rustdesk（AGPL-3.0，git subtree 固定 tag 引入，保留上游历史）
- server/ = 上游 hbbs/hbbr 容器（一行不改）+ 自研 console（Rust axum + SQLite + askama，单二进制）
- build/config.toml = 品牌及网络默认值的构建期注入口；服务器/公钥/网段/模式仅可由它或本机受控高级设置显式配置，仓库只提交 config.toml.example

## 硬性约束（违反即打回）
1. 最小侵入：client/ 上游代码每处修改加 // HOMEDESK: 标记；新逻辑放独立文件/模块；
   禁止重排或重新格式化上游代码——必须保住季度 rebase 上游安全补丁的能力
2. 不碰核心：传输协议、编解码、加密逻辑零改动；只做配置、UI、外围模块
3. 配置外置：品牌/服务器/Key/网段/模式禁止硬编码；构建默认走 build/config.toml，运行时变更只允许本机受控高级设置显式校验并保存
4. 零密钥入库：真实 IP/公钥/Token 只出现在未跟踪的本地配置中；example 文件仅放占位值；CI 跑 gitleaks，检出即失败
5. console 质量线：所有 API 带单元测试；单二进制；零额外运行时依赖
6. 依赖锁定：Cargo.lock 与镜像 tag 固定版本；依赖升级单独开 PR
7. 双模式网络边界：客户端默认 lan_only，不发起任何公网请求；只有构建默认或本机受控高级设置显式选择并通过整组配置校验的 self_hosted，才允许访问自建公网 hbbs/hbbr、必要 DNS、经审核的打洞服务及当前连接需要的对端公网地址。校验失败保留上一份有效配置，不得静默改模式或扩大权限；两种模式始终禁止上游公共服务器回退、遥测和自动更新

## 工作方式
- 每个任务先读 DESIGN.md 对应章节再动手
- 每 PR 三件套：目标平台编译通过 + tests/smoke.md 勾选记录 + 变更说明（动了上游哪些文件、为何）
- 小步提交：feat(client): / feat(console): / chore(build): 前缀；正文列出上游改动文件清单
- 注释、文档、UI 文案一律中文
- 方案有歧义时：按上游 RustDesk 默认行为实现，代码处留 TODO(design) 注释，
  汇总到 DESIGN_QUESTIONS.md 等我确认
```

## 五-A、自建公网 P2P 增量阶段（T-17 → T-19）

本阶段只扩展显式 `self_hosted` 模式。默认 `lan_only` 的零公网出站及原局域网兼容入口保持，但不能宣称原始 IP 路径已加密；公网模式拒绝这条非安全旁路，保留经 hbbs 撮合的同网段 P2P。上游公共服务器回退、遥测和自动更新在两种模式下始终禁止。Console 仍只允许内网或 VPN 访问。

**T-17 · 上游公网兼容性验证**

```
目标：在不改传输协议、编解码和加密核心的前提下，用固定官方客户端 RustDesk 1.4.9

任务：
1. 以两个真实独立外网建立 TCP P2P 与受控阻断直连后的 hbbr 回退，连续记录实际连接类型、
   加密、建连耗时与端口/协议；P2P 不按“必为 UDP”判定。UDP/IPv6 分别记录，未验证时保持关闭。
   “UDP 会话关闭”仅指可选 UDP/KCP 会话路径，不得误关 hbbs UDP 21116 注册/心跳/打洞协调；
   报告须分开标记协调流量和实际会话流量。
2. 梳理 self_hosted 所需的自建 hbbs/hbbr、必要 DNS、经审核打洞服务和对端公网地址，形成 T-18
   的精确允许清单。官方客户端观察到的默认更新、公共 STUN 等额外出站须单列为待拦截项；T-17
   不要求未定制官方客户端已满足 HomeDesk 的零遥测/零公共回退，T-18/T-19 定制产物必须证明。
3. 验证服务端 Key 只用于服务器身份校验，远控密码仍由被控端校验；不得引入中央授权。
4. 专项核对错误/缺失服务器 Key、对端签名或 ID 不符及锁定版本非安全回退；对下列目标规则核查现状，
   将缺失项交给 T-18 实现，不把官方客户端描述为已有过滤：候选只接受当前配置
   服务器连接中当前请求的原生响应，并按目标 ID/连接类型/生命周期关联，拒绝过期取消结果。
   连接前拒绝非法端口及未指定/回环/链路本地/组播/广播地址；同 LAN 私网候选仅在上游标记
   本地且命中显式家庭 CIDR 时允许，中继只允许当前部署配置的主机端口。地址过滤不代替上游握手。

未验证或不支持时标明并保持关闭，不阻塞已验证的 TCP P2P + 中继。不得承诺任意网络直连。
若错误/缺失 Key、对端身份不符或非安全回退无法通过既有握手、配置和外围策略拒绝，停止公网发布；
```
